NonnoAlex is a public, read-only personal website. It does not provide user accounts, payments, comments, uploads, newsletters, or a contact form. The site does not intentionally set first-party advertising cookies or run a first-party behavioral analytics service. Information you send through an external profile such as GitHub or LinkedIn is handled by that service under its own terms and privacy policy, not by this website.

Like most websites, the hosting and network providers may process basic technical request data needed to deliver and protect the service. This can include an IP address, request time, requested URL, browser or user-agent information, referrer, response status, and security signals. Such data may appear in short-lived server, proxy, or security logs and may be used to diagnose faults, prevent abuse, and maintain availability.

Pages load fonts from Google Fonts and the home page loads a public contribution image from `ghchart.rshah.org`. A visitor's browser therefore makes requests to those services, which may receive technical request information such as an IP address and user-agent string. Links to GitHub, LinkedIn, Osmosis, Credly, and other external websites take you outside NonnoAlex; their privacy practices apply after you follow those links.

This site publishes only material intended for public reading. If a page contains inaccurate personal information or content that should not be public, use the routes on the [contact page](/contact/) and include the exact URL. This notice may change when the site's features or service providers change. Last updated: 31 August 2026.
