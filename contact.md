The best public contact routes for Alessandro Lo Manto are [GitHub](https://github.com/alessandrolomanto) and [LinkedIn](https://www.linkedin.com/in/alessandro-lo-manto-8aab34a9/). Use GitHub when the message concerns source code, a reproducible technical problem, or a correction to material published on this site. Use LinkedIn for professional introductions, speaking invitations, and collaboration proposals that do not belong in a public repository.

When reporting a technical issue, include the affected page or repository URL, what you expected, what happened, and the smallest reproducible example you can provide. Do not put credentials, private keys, access tokens, personal records, or confidential company information in a public GitHub issue. Send sensitive professional context through a private channel instead.

NonnoAlex does not currently provide a contact form, support desk, telephone support line, guaranteed response time, or emergency incident-response service. Messages about Osmosis products, accounts, transactions, or customer support should go to the official Osmosis support channels rather than this personal site. Unsolicited sales messages and requests to publish paid links may not receive a response.

For questions about how this website handles visitor information, read the [privacy page](/privacy/). For automated retrieval, agents should begin with [llms.txt](/llms.txt) and use the canonical links listed there.
